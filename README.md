# 小树游戏屋

一个为 iPad 设计、没有广告且支持离线运行的家庭小游戏 PWA。

目前可以玩 20 款游戏。大厅是图标加名称的桌面式网格，支持分类筛选、最近玩过的 4 款
游戏，以及「整理图标」进入编辑模式后长按拖动调整顺序：

- 2048（触摸滑动或使用方向键，自动保存进度）
- 五子棋（默认和电脑玩，也支持同屏双人对战）
- 俄罗斯方块（键盘与屏幕按钮、七袋随机、幽灵落点和等级系统）
- 合成水果（Matter 圆形物理、连锁合成、危险线和十一种原创水果）
- 空当接龙（拖牌或点选移动、四个空当、多牌组移动、花色回收区，排好残局自动收完）
- 蜘蛛纸牌（一花色入门模式、拖序列或点选、两副牌、五轮发牌和自动收组）
- 扫雷（初级与中级、首点安全、触屏插旗和数字快捷展开）
- 记忆翻牌（12/16/24 对、水果/动物主题、单人或亲子轮流）
- 七巧板（标准七块、五幅轮廓含房子/帆船、剪影模式接受不同合法拼法、拖动吸附、45° 旋转/翻面、撤销与提示）
- 接水管（4×4 至 6×6、可解管网、撤销与单格提示）
- 推箱子（30 个已验证可解关卡、选关页、按步数评星、点相邻格/方向按钮、撤销与求解提示）
- 泡泡龙（反弹瞄准线、四色基础或五色挑战、三连消除、悬空消除、下一颗与交换、撤销、不限时）
- 点泡泡（泡泡上升渐大、点破计分越小越高、金色三倍、基础/进阶/挑战渐进加速、限时）
- 红包雨（红包落下点开收福、连击加倍、炮仗扣分、限时挑战）
- 打地鼠（九洞地鼠、连击加倍、睡帽鼠宝宝不能打、限时挑战）
- 切水果（木质切割区、跟手刀光、带果肉的半果飞散、同次挥刀累计三果奖励 +3、小心炸弹）
- 解绳结（6-9 个点、交叉线高亮、拖动、撤销与参考位置提示）
- 迷宫探险（7×7 至 11×11 可解迷宫、点相邻格或按住沿路拖动、撤销和路线提示）
- 数织（50 幅唯一解图案：5×5 组在前、10×10 组在后、连续划格、整笔撤销、线索完成提示与单格提示）
- 数独（6×6/9×9 唯一解题、候选数笔记、同数/冲突高亮、撤销、擦除与提示）
- 水排序（试管倒水归单色、三档难度、必可解生成、撤销与续玩）
- 停车场（6×6 滑车解谜、单指直接拖车、把红车开出出口、最少步数提示、撤销与续玩）
- 叠叠消（多层叠放水果三消、7 格槽、槽满给免费撤销与洗牌不清盘）
- 纸牌（经典 Klondike 翻一：拖牌或点选、翻牌堆重翻、基础堆回收与残局自动收完）

背景音乐和操作音效均在本地生成，可在游戏内开关。完成首次离线资源缓存后，所有游戏
都可断网打开。数独、数织、推箱子会自动保存当前棋盘和最近 50 步撤销记录；再次进入
可选择继续或重新开始。其他新增益智游戏保存完成标记、关卡进度和最好成绩，不保存棋盘。
所有数据仅保存在本机，清理网站数据也会清除进度。

大厅使用统一的本地 SVG 图标，不受系统 emoji 字体差异影响。动作游戏的粒子在点击位置
爆开、渐隐并回收，每种纹理最多保留 64 个粒子；连续操作的声音最多同时使用 24 个声源。
泡泡有透明高光与金色标记，红包带金币封印。现有水果图片仍由两个本地图集提供。

记忆翻牌按单/双人分开记成绩，泡泡龙按颜色难度分开；接水管、解绳结、迷宫、推箱子
区分独立完成与提示练习，使用提示后撤销也不会变回独立成绩。旧成绩保留为未分模式的历史记录。
四款动作游戏（点泡泡/红包雨/打地鼠/切水果）按基础/进阶/挑战分别记最高分，
节奏调整前的旧纪录显示为「历史最高（旧节奏）」。
迷宫记录比最短路线多走的步数；推箱子独立完成评星，提示练习显示完成勾号。

七巧板切换剪影模式会重开当前图案，隐藏分块提示，只留整体剪影；允许同形块互换及不同
合法分块，但不能越界或重叠。提示采用参考拼法，可撤销恢复之前的摆放。接水管、迷宫和解绳结
可以生成新题。所有新增游戏默认不限时，不含广告、付费、追踪或远程素材。

## 本地开发

```bash
pnpm install
pnpm dev --host
```

电脑和 iPad 连接同一个局域网后，可以在 iPad Safari 中打开终端显示的网络地址进行真机调试。

## 检查与构建

日常修改按影响验证，不必每次跑全量。例如只改五子棋规则：

```bash
pnpm exec tsc --noEmit
pnpm exec vitest run tests/gomoku/game.test.ts
```

纯文档核对内容和链接并运行 `git diff --check`；单游戏 UI 做目标游戏的操作验收。
共享基础设施或发布批次再运行下面的全量检查。具体触发条件和结果复用规则见
[AGENTS.md §10](AGENTS.md#10-测试与验收)。

```bash
pnpm check
pnpm preview
```

另开一个终端运行开发服务后，可运行真实浏览器回归（默认使用 macOS Chrome）：

```bash
pnpm test:browser
```

脚本使用独立临时浏览器数据，不改平时浏览器的存档；检查 iPad 横竖屏、触控划格、数独笔记、
续玩、音频开关、返回边界和高难度操作，截图保存到输出的临时目录。可用 `APP_URL` 指定
开发服务地址、`CHROME_PATH` 指定 Chromium 路径。真机 Safari / 主屏幕 PWA 仍需单独验收。

生产文件输出到 `dist/`，应部署到支持 HTTPS 的静态网站服务。
