# 小树游戏屋

一个为 iPad 设计、没有广告且支持离线运行的家庭小游戏 PWA。

目前可以玩 15 款游戏：

- 2048（触摸滑动或使用方向键，自动保存进度）
- 五子棋（默认和电脑玩，也支持同屏双人对战）
- 俄罗斯方块（键盘与屏幕按钮、七袋随机、幽灵落点和等级系统）
- 合成水果（Matter 圆形物理、连锁合成、危险线和十一种原创水果）
- 空当接龙（点选移动、四个空当、多牌组移动与花色回收区）
- 蜘蛛纸牌（一花色入门模式、两副牌、五轮发牌和自动收组）
- 扫雷（初级与中级、首点安全、触屏插旗和数字快捷展开）
- 记忆翻牌（3/6/8 对、水果/动物主题、单人或亲子轮流）
- 七巧板（标准七块、三种方向轮廓、拖动吸附、45° 旋转/翻面、撤销与提示）
- 接水管（3×3 至 5×5、可解管网、撤销与单格提示）
- 推箱子（5 个已验证可解关卡、点相邻格/方向按钮、撤销与求解提示）
- 泡泡龙（反弹瞄准线、三色三连消除、悬空消除、下一颗与交换、撤销、不限时）
- 解绳结（5/6/7 个点、交叉线高亮、拖动、撤销与参考位置提示）
- 迷宫探险（5×5 至 9×9 可解迷宫、点相邻格/方向按钮、撤销和路线提示）
- 数织（5 幅唯一解 5×5 图案、填色/标空、撤销与单格提示）

背景音乐和操作音效均在本地生成，可在游戏内开关。完成首次离线资源缓存后，所有游戏
都可断网打开；新增八款的当前牌局/关卡进度只保留在本次游戏内，退出后重新开始。

七巧板目前是带分块轮廓的入门版；推箱子和数织各有 5 个精选关卡。接水管、迷宫和解绳结
可以生成新题。所有新增游戏默认不限时，不含广告、付费、追踪或远程素材。

## 本地开发

```bash
pnpm install
pnpm dev --host
```

电脑和 iPad 连接同一个局域网后，可以在 iPad Safari 中打开终端显示的网络地址进行真机调试。

## 检查与构建

```bash
pnpm check
pnpm preview
```

生产文件输出到 `dist/`，应部署到支持 HTTPS 的静态网站服务。
