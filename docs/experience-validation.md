# 体验优化验收记录

本轮针对 Zcode 交付的 16 款游戏进行适配、存档、规则、交互和性能完善，没有发布线上。

## 行为变化

- 10×10 数织每格点击区域由约 40 个逻辑像素扩大为 52，横屏约 44px；支持单指连续
  填色/标空/擦除，跨格插值补齐，整笔撤销。满足当前行列线索时淡化提示，不偷看答案判错。
- 七巧板工具栏分开排布；新增房子和帆船。剪影判定检查实际轮廓覆盖与重叠，不再绑定每块
  的固定目标；接受同形块互换及跨参考分块的合法拼法。切换模式重开本图，提示采用参考拼法。
- 数独增加候选笔记、相同数字高亮，笔记随棋盘撤销/保存，填数时移除同行/列/宫冲突候选。
  键盘数字填数，N 切换笔记，Backspace/Delete 擦除。
- 数独、数织、推箱子保存棋盘和最近 50 步撤销，重新进入提供继续/重新开始；损坏的棋盘
  拒绝恢复，非法撤销记录过滤；旧数独存档缺少笔记时兼容为空。后台/退出有同步本地备份。
- 记录按单/双人、难度、独立/提示练习区分，旧记录保留而不冒充独立成绩。迷宫记超过最短
  路线的步数，推箱子仅独立成绩评星，练习完成显示勾号。
- 大厅按数字逻辑、图形路线、轻松反应、棋类纸牌分类；最近玩过最多四款，仅本机保存。
- 场景的停止和销毁两条路径均释放后台/离开监听器，销毁后异步回调不得重建画面。
  同时通过 pnpm 本地补丁修复 Phaser 4.2.1 自身的可见性监听器销毁遗漏；没有升级引擎或新增
  运行时依赖。浏览器回归要求重复进出前后监听器数量相等，防止越玩越慢。

## 自动与浏览器验收

- `pnpm check`：24 个文件、126 项测试，类型检查和生产构建通过。
- `git diff --check`：通过。
- `pnpm test:browser`：独立临时 Chrome，768×1024 与 1024×768。
  检查数独笔记/撤销/续玩、数织真实触控连续划格及整笔撤销、七巧板完成、音频用户手势解锁
  和静音恢复、离开后关闭音频、大厅分类/最近入口、首页退出确认、高难度操作及反复切换。
- 生产 `preview`：完成 Service Worker 缓存后禁用网络，重新加载大厅并逐一进入全部 16 款
  游戏，Canvas 均建立且没有运行时异常。此项验证离线装载，不代表断网下逐局通关。
- 保留了较小迷宫格子的等价大方向按钮；没有强制旋转或因横竖屏切换重开棋局。

## 性能测量

本机 Chrome、4 倍 CPU 降速、9×9 数独，连续 20 次选格更新：

| 指标 | 调整前 | 调整后 |
| --- | --- | --- |
| 场景更新耗时范围 | 约 230–333ms | 多轮测试约 2–16ms |
| 中位数 | 约 257ms | 约 4–6ms |

采用复用格子和文字，仅更新变化内容；选格不重新序列化存档。数织划格也复用棋盘对象，
浏览器回归检查划格前后对象数不变。动画、音频和输入规则没有为了节省性能而关闭。
这不是 iPad 真机帧率承诺；数独生成器随机耗时仍有波动，本轮未增加 Worker 或新依赖。
最终连续进出 8 次的回归中，GC 后 DOM 节点均为 528、监听器均为 40，没有逐次累积。
`pnpm install --frozen-lockfile --offline` 也已通过，框架补丁可通过锁文件复现。

## 尚需真机确认
