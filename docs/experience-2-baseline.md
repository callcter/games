## 当前行为实录（按方案第 1 节五项瓶颈对照）

### 停车场（E2-100 改造对象）

- 主交互是「点车 → 出现绿色目标格 → 点目标格 → `move()` → 整盘重绘」；
- 拿起汽车没有视觉反馈（无放大 / 无阴影变化 / 无 pickup 音效）；
- 拖动不存在：孩子无法按住车直接拖，只能理解「先选再点」的命令式 UI；
- 移动瞬间画面整盘刷新，没有车体滑动的过程感；
- 状态行文案「要点亮着的牌，不要去碰其他车」是操作说明书式长句。

### 合成水果

- 投放是「点击 x 坐标 → 立即生成」，无预览跟手、无落点提示；
- merge 有放大 + 音效，但生成是单纯变大，无 squash→pop 弹性；
- 无连锁表现（500~700ms 连续 merge 与普通 merge 观感相同）。

### 切水果（Game Feel 基准）

- 已有跟手刀光、whoosh、线段切割、半果分离、果汁粒子、combo 浮字——保留；
- intro 是「标题 + 玩法长句 + 三枚难度文字按钮」，视觉中心是设置页式按钮排布；
- HUD 用 puzzle 风格长句状态行（分数/已切/剩余秒数拼一句）；
- 结束 `endRound()` 调 `resetView()`：游戏世界消失，进入统一结算文字页，
  「再来一次」与「换个难度」两枚等宽按钮（replay 已存在但非强主按钮层级）。

### 大厅

- 信息架构以成人运维功能为先：检查更新 / 整理图标与「最近玩过」同级抢视觉；
- 分类是工程语言（数字逻辑 / 图形路线 / 轻松反应 / 棋类纸牌）；
- 卡片无按压反馈。
