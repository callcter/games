# 本地美术与反馈维护

本轮基于 Zcode 的 `28b8316` 继续开发，保留其 20 款游戏、图标排序、自动收牌、
水果图集和切面绘制。不修改玩法、计分或难度，不添加依赖和运行时外部请求。

## 图像

- `src/app/icons.ts`：20 款游戏的代码原生 SVG，64×64 viewBox。大厅和最近玩过共用，
  没有 DOM id、远程引用或额外焦点，图标文字由按钮标题提供。
- `public/art/fruits-small.png`、`fruits-big.png`：沿用 Zcode 的生成素材，本轮不替换。
- 泡泡透明底色、弧形高光、彩色反光边缘和金色十字，以及红包金币封印，均由 Phaser 绘制；
  这些简单图形适合矢量实现，本轮没有调用图像生成服务，也没有新建位图素材。
- 数量不变但实体换新时，也必须同步纹理/颜色；尤其不能把炸弹误显示为普通水果。

## 粒子与生命周期

- `ActionScene.onRoundInput()` 注册回合输入，`resetView()` 移除回合监听、停止补间并销毁内容。
- 粒子发射器固定 `(0, 0)`，`explode(count, x, y)` 传局部坐标，避免重复偏移。
- 同一纹理每回合复用一个池，最多 64 个存活粒子，一次最多 24 个。速度和寿命由首次创建
  配置，同一纹理保持一致。没有每次点击的临时发射器或销毁计时器。
- 地鼠的离屏遮罩随所有者销毁；不能仅依赖动画完成回调，否则提前离开会遗漏清理。
- 切水果半果改为本地 Canvas 裁切烘焙的 128×128 透明纹理，不再使用世界坐标遮罩；
  保留切中瞬间旋转，绘制果肉截面，两个半果继承部分水果速度并沿切线法向分离、受重力下落。
  临时纹理在图片销毁时删除，包括结算和退出路径。

## 声音

- “啵”声用短正弦滑音叠加低音量滤波噪声，依旧完全本地生成。
- 总声源上限 24；结束时断开节点，静音时不调度背景音符，暂停的音频上下文不排队播放音效。
- `dispose()` 后禁止重新解锁；Safari 异步解锁完成后再检查实例是否已释放。
- 自动测试能确认解锁、静音、声源和节点生命周期；听感与 iPad 扬声器效果仍需真机试听。

## 验证入口

`pnpm check` 包含 30 个测试文件、155 个测试。`pnpm test:browser` 需要先启动本地开发服务，
检查横竖屏、四款动作游戏的真实输入、连续重玩监听数、粒子位置和数量上限。
浏览器测试期间不要改源码，以免 Vite 热更新重载打断正在运行的测试。

## 切水果对标（2026-09-17）

参考 [Halfbrick 官方入门指南](https://www.halfbrick.com/blog/the-ultimate-beginners-guide-to-fruit-ninja)：
原作将一次挥刀切中至少三个水果视为连切，并有 Classic、Arcade、Zen 三种基础模式。
本项目借鉴操作与反馈，不复制原作美术、品牌、付费或联网机制。

本轮新增木质切割区、双层渐细刀光、挥刀风声、分色果汁与短暂果汁印记、真实透明半果。
修复按住超过刀光寿命后不能继续切的问题。规则变更：连切从单个输入事件改为整次手势累计，
仍保持三个起 +3 且每次手势最多奖励一次，不采用原作的翻倍计分。
保留现有 60 秒、漏果不惩罚、炸弹扣 5 秒和三档难度，因此不是原作模式的完整复刻。
后续可以分别引入无炸弹练习与经典三次漏果模式，以及更成组的抛果节奏；需独立测试、明确
成绩隔离和儿童默认难度后再实现。
