# 2026-09-18 全量 UI 截图审查

范围：大厅 + 实际注册的 24 款游戏，768×1024、1024×768。保留现有功能和素材，
不改规则、难度、存档或逻辑画布尺寸。截图由 `AUDIT_ONLY=1 pnpm test:browser` 生成，
包含大厅全页、初始页面、续玩后的棋盘和四款动作游戏运行画面。

## 问题与处理批次

1. 公共界面：深色/复杂背景上的标题和状态难读；按钮直角、层级弱；背景在画布内外重复且断层。
   加浅色信息底板、圆角按钮和选中/按下反馈，画布外使用主题底色。
2. 动作游戏：难度入口分散在背景上，缺少开始引导。集中到说明卡，保留点击难度立即开始。
3. 俄罗斯方块：768 高横屏仍使用长侧栏，预告与按钮重叠。改为紧凑侧栏。
4. 记忆翻牌：卡背单薄，初始棋盘偏上。增加圆角卡面和背纹，居中棋盘。
5. 接水管：未连通管道与格底对比弱。加深管道并增加内层高光。
6. 数织：五格图案的线索距离格子过远。收紧线索间距并补充线索底带。
7. 水排序：背景硬拉伸、试管浮在复杂景物上，水层底部与玻璃底部不齐。等比背景、棋盘底板及液柱内沿修整。
8. 大厅：图标相对卡片偏小。增加图标尺寸，降低多余阴影，加强卡片边界。

## 验收限制

Chrome 模拟触控、横竖屏与音频状态不能代替 iPad Safari 真机和人耳听感。

## 验收结果

- 初始全量截图 50 张；最终截图 68 张（额外包含 10 张棋盘状态、8 张动作运行状态），逐张复核。
- `pnpm check`：38 个测试文件、222 项测试通过，生产构建成功。
- 完整 `pnpm test:browser`：横竖屏触控、难度切换、撤销、存档续玩、音频、动作游戏重玩、监听器释放通过。
- `RENDER_ONLY=1 pnpm test:browser`：8 款游戏 × 两种尺寸 DPR=2 通过；增加旧游戏头部按钮真实点击断言。
- 截图脚本增加全部卡片加载等待，防止空列表误报通过；导航等待兼容 CDP 在重载时短暂失去上下文，其他错误仍立即失败。
- 本地对照入口：`test-results/ui-audit/index.html`（生成物，不提交）；完整最终画廊在 `after/index.html`。
- 无规则、难度或存档格式变更。俄罗斯方块低于 850px 的视口使用紧凑侧栏，只展示下一块，避免覆盖操作区。
