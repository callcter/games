## 架构重点与待复现项

- 保持 core、存档格式、玩法与依赖不变；本批修 UI 集成，不借机重写所有场景。
- `puzzle-kit` / `action-kit` 共用 768 宽、900–1680 高的挂载和内容平移；
  `createPuzzleChrome` 属于屏幕层；纸牌及独立场景仍有自己的尺寸、布局职责。
  “共享组件”不等于所有场景已完成一致的布局约束。
- `scene-modal.ts` 的旧弹窗在 POST_STEP 恢复时无条件删除当前弹窗映射。
  需复现同帧关闭再打开后是否失去单例保护；确认后先补回归，再修复归属判断。
- 继续核对 fluid 内容坐标、动作游戏结算与旋转、共享按钮命中/抬手行为。
  未复现项不能混写为已修复。

开发期间只做目标复现和类型检查；共享层稳定后一次 `pnpm check`。
